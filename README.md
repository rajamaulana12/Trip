# Aceh Trip — Jelajahi dengan Tenang

Panduan perjalanan digital interaktif untuk menjelajahi destinasi wisata, kuliner & UMKM lokal, serta akomodasi ramah Muslim di Aceh (Banda Aceh, Sabang, Aceh Besar, Aceh Tengah, dan Bener Meriah).

## Fitur Utama

- **Katalog Destinasi**: Pencarian, filter wilayah, filter kategori, pengurutan biaya/nama, modal detail dengan tautan Google Maps, serta simpan ke favorit.
- **Peta Wilayah Ilustratif**: Ringkasan 5 wilayah eksplorasi Aceh dan informasi fasilitas ramah Muslim.
- **Kuliner & Akomodasi**: Daftar kuliner lokal/UMKM dan penginapan dengan transparansi status verifikasi.
- **Itinerary Planner & Kalkulator Anggaran**: Susun rencana perjalanan 1–5 hari dan hitung estimasi biaya secara otomatis.
- **Rekomendasi Paket Wisata**: Filter paket berdasarkan minat, durasi maksimal, dan batas anggaran.
- **Dashboard Pengelola Lokal (Demo CMS)**: Proteksi PIN demo (`1234`), tambah/edit/hapus data, unggah foto terkompresi, dan penyimpanan lokal di `localStorage`.

## Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

Build produksi:

```bash
npm run build
```
